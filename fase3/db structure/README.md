# Estructura documental de MongoDB

Estos cuatro JSON describen las **rutas y tipos BSON** que construye `scripts/mongodb/02_load_processed.js`. Son mapas de estructura para lectura y documentación; **no son registros reales**, no se importan como datos y no sustituyen los validadores JSON Schema de `01_create_collections.js`. `null` indica que una propiedad puede no tener valor. Los arreglos muestran la estructura de sus elementos, no cantidades ni ejemplos ficticios.

Para consultar documentos reales sin modificar la base, seguir `docs/Evidence/Evidences_Fase3.md`.
